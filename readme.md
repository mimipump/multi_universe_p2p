这是一个宇宙的抽象的网格框架,用于娱乐的.
## 项目1 multi_universe_p2p
一个运动的宇宙,无限广大,有自洽且真实的物理.  
任何用户在任何人在任何情况下都可以登陆到这个世界,基于分布式技术与架空设定去实现这一点.
本质上这个项目是服务于electronic_soul
### 项目构成
#### 宇宙软件框架
- 空间及物质能量框架
  - space_cell: 由自下而上的二叉树索引的三维区域网格网格.
    - binapather: 便于未知坐标地随机访问任意距离外的cell数据的数据结构以及索引方式,特点为无坐标与随意拆解拼接.在大尺度随机访问上有优势,而且适用于分布式存储与加载.
  - object: 游离于space中的voxel构造体.作为整块的voxel数据被空间相关的高效数据结构索引.
    - 人造物
    - 天然物
    - 智能体
  - 质能互作系统: 全宇宙实时互作与更新方案.
    - 物质:
      - 宏观物质(网格物质):数据量相关的一种对象
        - 密度=顶点数/体积 :密度与物质类型相关,密度可以相当于物质类型.可以类比为物态变化以及化学反应的变化简化为直接的密度变化.  
        
      - 微观物质(用场描述分布或运动):
        - 电磁
        - 引力
        - 粒子流(任何需要的粒子):现场预制
    - 能量:
      - 动能:包含运动\形变 ......
    - 其它:
    - 互作:
    - 熵:熵增等于"在场人数*变化的信息量*在场时间*w(d)-在场人数*在长时间*(1-w(d))*1/(S+1);[暂定]  
        w(d)=1/(d^2+1)
        也许应该有能量变化对熵增的影响
    - 仿真系统:简易的,步进采样的,
- AI替身系统: 用于用户离线后角色的生活.
- 账簿合并系统: (包括版本升级)
  - 世界影响合并时根据不同世界相同区域的熵权重进行投票.
#### 世界观设定
- 现象级
  - 质能互作: 必然不是全真模拟.
    - 第一性原理.
    - 解释性补充.
  - 不稳定区: 用于离线行为的规定.在已有数据的宇宙space中,本地没有该区域数据的角色登陆该区域时该区域对于角色判定为不稳定空间,空间中的行为将由该方法干预,主要体现在合并世界中或合并世界后的现象.
  - 熵值与魔法:一些魔法来源原理可以认为将局部逆熵存储进某种东西里
